# FUNCTIONAL_MAP

## Ключевые функциональные домены
1. **Заказы ремонта**: список, фильтрация, создание/редактирование карточки, статусы, выдача/приём.
2. **Клиенты**: реестр клиентов, добавление, редактирование, привязка к заказам.
3. **Склад/ЗИП**: каталог запчастей, добавление позиций, списание/привязка к ремонту.
4. **Печать и документы**: акты приёма/выдачи, редактор актов, экспорт.
5. **Коммуникации**: SMS, трекинг почты.
6. **Администрирование**: авторизация, регистрация, группы доступа, настройки.
7. **История/аналитика**: история изменений, графики, состояния.

## Связь UI → данные
- `Form1` + `Editor` ↔ `catalog`, `historybd`, `statesmap`, `stockmap`.
- `ClientsEditor`/`ClientAddForm` ↔ `clientsmap`.
- `Stock`/`StockEditor`/`StockAddPosition` ↔ `stock`, `stockmap`.
- `Authorisation`/`Registration`/`Settings` ↔ `users`, `groupdostup`.
